# Security

Volpi keeps your research on your computer, so we take security problems seriously.

## Reporting a security problem

**Please do not report security problems in public issues or public Discord channels.**

Report them privately instead:

1. On GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer can see these reports.
2. If that option is not available to you, send the maintainer a private message on [Discord](https://discord.gg/gkHMSq6emT). Say only that you have found a security problem, and wait for a private place to share the details.

Please include:

- the Volpi version and your operating system,
- what the problem is and what someone could do with it,
- the steps to reproduce it, as far as you can.

Do not include your own research or anyone's personal data. A small example is enough.

## What counts

For example: Volpi sending data it should not, a file that can make Volpi run code it should not, or a way past a profile password. The privacy policy on the website (`/privacy/`) lists everything Volpi is supposed to send.

Note that a profile password locks a profile inside Volpi; it does not encrypt your files. That is a documented limit, not a security bug.

## Supported versions

Volpi is in its first beta. Fixes go into the latest version, so please make sure you are on it before reporting.
